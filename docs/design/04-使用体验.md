# 使用体验设计

> 关联：D14（掌握兜底 + 错题板 + 小结页）、`03-记忆曲线与复习.md`
> 目标：把 D15 的 7884 义项 + 新 SRS，落到"每天愿意打开 10 分钟"的具体交互上。

---

## 1. 首页要回答的唯一问题

用户每天打开 App，只想知道一件事：**今天该练什么，练到什么程度算够。**

所以首页只有三块，别的一律不放在首屏：

```
┌──────────────────────────────────────┐
│  考研 · 义项判别                      │
│  ┌────────────────────────────────┐  │
│  │  今日 8 / 20 题                 │  │  ← 唯一的数字
│  │  ▓▓▓▓▓▓░░░░░░░░░░░░            │  │
│  │  3 个陷阱义项待攻克             │  │  ← 引导，不催促
│  └────────────────────────────────┘  │
│  [    继续训练    ]                    │  ← 主按钮，60% 宽
│  [练 1 题]                            │  ← 次要，20% 宽
│                                      │
│  ── 底部导航 ──                       │
│  练习   生词   错题   我的             │
└──────────────────────────────────────┘
```

**不做**：倒计时、连续打卡天数、排行榜、成就、进度环动画。
这些是"产品"的需要（规格 §1.1 已裁撤），不是"学会"的需要。

## 2. 答题流：整场只有两个动作

一场 10 题 = **10 次「先猜 → 再看」**。任何额外操作都是摩擦。

### 2.1 三步循环

```
┌── 第 1 步：读题（无选项）──────────────────┐
│                                            │
│   4/10                                      │
│                                            │
│   She runs a small bakery with              │
│   her sister.                               │
│   ─────────                                 │  ← clue 下划线高亮
│                                            │
│   点击任意处显示选项 ↓                       │
└────────────────────────────────────────────┘
                    ↓ 点击
┌── 第 2 步：判别（5 选 1）──────────────────┐
│                                            │
│   跑    赛跑    奔跑的路程    经营    流动    │  ← 2 列网格
│                                            │
│   ┌──────────────────────────────────┐     │
│   │       我不会                      │     │  ← 通栏置底
│   └──────────────────────────────────┘     │
└────────────────────────────────────────────┘
                    ↓ 点击
┌── 第 3 步：讲解 ──────────────────────────┐
│                                            │
│   ✓ 经营                                   │  ← 正确答案，绿色，置顶
│                                            │
│   译文：她和姐姐一起经营着一家小面包店。      │
│                                            │
│   解析：run a business 是固定搭配，          │
│        此处是「经营」不是「奔跑」。           │
│                                            │
│   [再做一次]  [下一题]  [这题有毛病]        │
└────────────────────────────────────────────┘
```

### 2.2 关键交互细节

| 决策 | 理由 |
| --- | --- |
| **选项默认隐藏**，必须先读句 | 规格 §2.3 红线：不看选项直接选 = 识别；先想再看选项 = 判别 |
| **点空白处**才显示，不是自动 | 强迫用户至少扫一遍句子，否则会养成盲选习惯 |
| **「我不会」通栏置底，不在网格里** | 视觉降级，但它必须**永远在同一个位置**（肌肉记忆） |
| 判分**不闪全屏**，只标正确项绿色 | 个人自用，闪烁 = 惩罚感 |
| 译文**不含**目标词的中文 | 避免"看答案对答案"的假学习 |
| 解析首句直接说"此处是 X 不是 Y" | 对抗义项判别最常见的错误 |

### 2.3 反馈时序

```
点击选项 → 150ms 内出判分（正确项变绿/错误项变红）
         → 200ms 后讲解区从上展开（240ms）
         → 下一题按钮出现
```

**慢 ≠ 弱**：点「我不会」**不计时、不惩罚**（规格 §7.1）。
超时设置默认关闭。

## 3. 句子轮换在体验上意味着什么

用户不该感知到"句子在轮换"，只该感知到**每次遇到的句子不一样**。

| 阶段 | 用户感知 | 实现 |
| --- | --- | --- |
| 同一义项第 1 次练 | 第一次见这句 | 优先 `seenCount=0` 的句 |
| 第 2-3 次 | "这句我好像见过" | 换池中另一句 |
| 第 4 次（仍错） | 又见这句 | `WRONG` 后 `seenCount` 归零，优先重现 |
| 掌握后 | 不再出现 | 连对 3 次 → retired |

**用户主动"这题有毛病"** → 立即换句，不等生成。
当场能继续做题（`01-句子生成与复用.md` §3.3 的硬要求）。

## 4. 错题板：可见但不干预

```
┌──────────────────────────────────────┐
│  错题板                    共 23 个    │
│  ─────────────────────────────────── │
│  ⣿ abandon · 遗弃        错 5 · 3天前 │  ← 按错次+时间排
│  ⣿ complete · 圆满的    错 3 · 1周前 │
│  ⣿ engage · 使参与      错 2 · 今天  │
│    take · 拿；带         错 1 · 2周前 │
│  ─────────────────────────────────── │
│  连续 2 次答对 或 点「我已学会」后移出  │
└──────────────────────────────────────┘
```

**关键：错题板不改变排布。** 它是你自己查弱的窗口，
不是算法插队的借口。真正的复现由 SRS 到期负责。

**单挑模式**：点一项 → 只练它，连对 2 次自动移出，可以随时退出。
这是"我想集中攻克某个词"的入口。

## 5. 生词库：只进不出，够用就行

```
生词库 (14)
  bakery      烤面包房
  suffice     足够
  ...
「其实我认识」→ 移除
```

- 点句中任意词 → 立即标记（可撤销），无上限；
- 生词库的目标词**优先进入次日第 1 题**（规格 §8.1）；
- 不做 40 个上限、不做插队算法——个人积压量小，简单够用。

## 6. 小结页：只在完整场次出现

```
┌──────────────────────────────────────┐
│  本场完成                             │
│                                      │
│  新学 3 · 对 5 · 错 1 · 不会 1         │
│                                      │
│  错过：engaged · 使参与               │  ← 点即单挑
│                                      │
│  攻克 1 个陷阱义项 ✓                   │  ← 正反馈落点
│                                      │
│  [再来一轮]   [看详情]                 │
└──────────────────────────────────────┘
```

**「练 1 题」不弹此页**。练一题就走，别仪式感。
**「攻克 1 个陷阱义项」是这个产品的核心成就**——
它比"连续打卡 30 天"更贴合真实目标。

## 7. 难度档：显式但默认自动

三档：`D1 简单(7-12词) / D2 适中(12-16词) / D3 难(14-20词)`

- 默认**自动**：根据近 10 场的 PENDING 率调整；
- 设置里可**锁定**某档（"我不想被自动调节"）；
- 只有明确信号才降档：同一义项连续 3 次 PENDING → 该义项难度 −1
  （规格 §7.1），**全局难度不因单题表现而变**。

## 8. 离线与网络

| 状态 | 表现 |
| --- | --- |
| 离线 | **全部功能可用**（内容本地）。生成入口显示"离线，将使用已缓存句子" |
| 联网 | 后台静默补句（Layer 2），**不提示、不打断** |
| 生成失败 | 静默降级到 Layer 3，用户无感 |

**顶栏不显示网络状态**。它对用户没有决策价值——
离线能用、联网更好，不需要让人操心。

---

## 9. 会话长度

| 选项 | 何时用 |
| --- | --- |
| **5 题** | 忙碌日/通勤 |
| **10 题**（默认） | 日常，约 6-8 分钟 |
| **20 题** | 周末突击，约 15 分钟 |
| **1 题** | "就练一个"

**目标时长而非题数**才是设计的锚：10 题 × 约 40 秒/题 = 7 分钟。
实测中若偏离超过 50%，改的是题数默认值，不是排期算法。

## 10. 视觉令牌（沿用规格 §10.3，微调）

```
背景      #0E1116 深色 / #F5F6F7 浅色
卡片      #161B22  圆角 12  弱阴影
主色      #4C8DF6  （克制，不用于大面积）
正确      #3FB950   错误 #F85149   中性 #9AA7B4
陷阱义项标记  #D29922（琥珀色，仅用于 TRAP 标签，全站唯一例外色）
句子      英文衬线 Noto Serif 20-22sp  行距 1.5
选项      ≥56dp 高
动效      出现120 / 判分150 / 讲解展开240  ms   尊重"减弱动效"
```

**高亮口径**：clue 词用下划线，不用荧光底（破坏阅读）。
无法字面定位的同义 clue（4 条）只高亮目标词，不显示下划线。

## 11. 明确不做

| 不做 | 为什么 |
| --- | --- |
| 倒计时 / 考试日期 | 焦虑来源，且考纲不公开可靠 |
| 连续打卡天数 | 断签惩罚会直接劝退 |
| 成就系统 | 自用产品，奖励无意义 |
| 社交/排行 | 无需 |
| 语音/发音 | 二期，当前主线是义项判别 |
| 写作/造句输出 | 违反判别红线（规格 §1.2） |
| 图表化的进度可视化 | 唯一曲线（到期正确率）已在进度页，不做更多 |
