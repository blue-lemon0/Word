# 记忆曲线与复习排期

> 关联：规格 §6（旧 SRS，`interval`/`ease` 简单表）
> 本文**替换**规格 §6。理由见 §1。

---

## 1. 为什么不用现成的 SM-2

规格 v2.4 §6 用的表：

```
答对 → interval × 2.0, ease + 0.05
答错 → interval = 1,      ease - 0.1
```

三个问题：

| 问题 | 后果 |
| --- | --- |
| `interval` 单位是**会话数**，不是天 | 今天练 3 场 = 3 个单位；明天练 3 场 = 又 3 个。真实间隔在 3~24 小时内剧烈波动，算法却认为等价 |
| 二分区间无中间档 | 1→2→4→8→16 是 2 的幂，遗忘曲线是连续的，指数增长会**必然错过**最危险的 3~7 天窗口 |
| 只有一个 `ease`，无法区分"难词"与"熟词" | TRAP 义项（熟词僻义）和生词用同一套参数，实际难度差 3 倍以上 |

**但也不直接上 FSRS。** FSRS 需要每个词至少 10 次复习记录才有稳定参数，
而本项目是**义项级**训练卡，7884 张卡上平均每张只练 10-20 次 ——
刚好在数据量边缘，且用户要"个人自用、不做多因子调参"。

**决策：FSRS-lite —— 借用其核心洞察（难度与稳定度分离），但用可解释的固定参数。**

---

## 2. 状态模型

每张义项卡有四个状态量：

| 字段 | 含义 | 范围 | 初始 |
| --- | --- | --- | --- |
| `stability` (S) | 记忆稳定度：能撑多少天不复习 | 0.1 ~ 365 天 | 首次答对后由初始 S0 决定 |
| `difficulty` (D) | 固有难度：这个词对我有多难 | 1 ~ 10 | 由 S0 决定 |
| `lastReview` | 上次复习时间 | 时间戳 | - |
| `reps` | 复习次数 | 整数 | 0 |

**关键点：`S` 和 `D` 分离。**
`D` 描述"这个词本身难"（几乎不变），`S` 描述"我目前记得多牢"（每次复习都变）。
这正是 FSRS 的核心洞察，比单一 `ease` 强。

---

## 3. 初始参数（S0 / D0）

按**义项类型**给不同初值，而不是所有人一个起点：

| 义项类型 | S0（天） | D0 | 理由 |
| --- | --- | --- | --- |
| 生词首次出现 | 0.6 | 8.0 | 极不稳，需要密集复习 |
| CORE 单义词 | 1.2 | 6.0 | 见过但没熟 |
| CORE 多义词 s1（主义） | 2.0 | 5.0 | 最熟悉 |
| CORE 多义词 s2+（**TRAP**） | 0.8 | 7.0 | 看起来会读，实际读错 |
| 低频词 / 低 tier | 0.5 | 8.5 | 几乎没印象 |

> **TRAP 给最短 S0 是本设计最重要的一条**。
> 用户的真实痛点是"abandon 我认识，但看不出是『使屈从』还是『遗弃』"，
> 所以 TRAP 卡必须**比其他卡更早、更频繁地出现**，直到读准为止。

## 4. 复习间隔

```
下一次复习间隔（天）= S × 间隔因子 × 当日场次修正
```

### 4.1 间隔因子

用 `ease_factor(D)` 代替固定倍数，让**难词增长更慢**：

```
ease_factor(D) = 1.50 - 0.12 × (D - 1)      clamp 到 [0.35, 1.50]

  D=1  → 1.50    最简单的词，长得最快
  D=3  → 1.26
  D=5  → 1.02
  D=7  → 0.78
  D=10 → 0.42    最难的词，长得最慢
```

整段无 clamp 截断（只在越界时生效），保证 **D 越大间隔单调越短**。
若把上限压到 1.4，D=1 与 D=3 都会落在 1.4，难度信号被抹平——
这是早期参数的错误，已修正。

| 当次结果 | grade | S 变化 | 到期天数 |
| --- | --- | --- | --- |
| `CORRECT`（答对） | 4 | `S × (1 + ease_factor(D))` | `S × ease_factor(D)` |
| `PENDING`（点不会/超时） | 2 | `S × 0.8` | `S` |
| `WRONG` | 0 | `max(0.1, S × 0.4)` | `max(0.25, S × 0.4)` 天（至少 6 小时后再现） |

> **2026-10-29：取消快/慢档。** 四选一 + 读句子的答题用时主要反映界面操作，
> 不反映记忆强度；同一张卡可能因为句子长短、走神、朗读而忽快忽慢。
> 现在答对就是答对，`elapsedMs` 只进作答流水，不参与排期。
>
> `WRONG` 后 `D += 0.8`，下次 `ease_factor` 自动变低，
> 增长自然放缓——不需要额外的惩罚规则。

**间隔下界**：任何情况下到期天数 ≥ 0.25 天（6 小时），
否则一口气连练会把当天所有卡刷成"已到期"。
**间隔上界**：`MASTER_S = 90` 天。算出来超过 90 天的部分直接截断，不再继续拉长。

### 4.1.1 实际推演（`app/tests/verify_srs.py` 实跑，非手算）

以 §3 的五类初值起步，各答对 4 次（D 不漂移），看到期间隔演化（天）：

| 类型 | S0/D0 | 第1次 | 第2次 | 第3次 | 第4次 |
| --- | --- | --- | --- | --- | --- |
| 主义 s1（D=5） | 2.0 | 2.04 | 4.12 | 8.32 | 16.81 |
| 单义（D=6） | 1.2 | 1.08 | 2.05 | 3.90 | 7.41 |
| TRAP（D=7） | 0.8 | 0.62 | 1.11 | 1.98 | 3.52 |
| 新词（D=8） | 0.6 | 0.40 | 0.66 | 1.09 | 1.81 |
| 低频（D=8.5） | 0.5 | 0.30 | 0.48 | 0.77 | 1.23 |

**s1 与 TRAP 的比值随复习次数拉开**：2.8x → 3.2x → 3.7x → 4.2x。
即熟词僻义卡会稳定落在主义卡约 1/3 的间隔上，
这正是设计意图：TRAP 更早、更频繁地重现。

**达到 90 天掌握门槛所需的连对次数**（答对不改 D，D 固定为初值）：

| 类型 | 需连对 | 到达 S | 到达 D |
| --- | --- | --- | --- |
| 主义 s1 | 6 次 | 136 天 | 5.0 |
| 单义 | 7 次 | 107 天 | 6.0 |
| TRAP | 9 次 | 144 天 | 7.0 |
| 新词 | 10 次 | 95 天 | 8.0 |
| 低频 | 12 次 | 141 天 | 8.5 |

> 新的义项要 6-12 次正确才可能"掌握"。这看起来多，
> 但因为间隔是**天**不是"场次"，一个义项跨越 3 个月练 7 次是正常节奏。
> 旧设计（连对 3 次即掌握）可以在同一天内达成，毫无记忆学意义。

### 4.1.2 逾期补偿（2026-10-29）

到期的卡晚了两周才答对，和准时答对拿到的下一个间隔**不应该一样**。
实际撑过的天数才是这次成功提取的证据：

```
有效间隔 = 计划间隔 + OVERDUE_CREDIT × (实际间隔 - 计划间隔)
下次间隔 = 有效间隔 × (1 + ease_factor(D))
```

`OVERDUE_CREDIT = 0.5`：超出计划的部分只认一半。

| 计划间隔 | 实际间隔 | 有效间隔 | 下次间隔（D=5, ef=1.02） |
| --- | --- | --- | --- |
| 7 天 | 7 天 | 7.0 天 | 14.1 天 |
| 7 天 | 14 天 | 10.5 天 | 21.2 天 |
| 16 天 | 30 天 | 23.0 天 | 46.5 天 |

为什么要折半，而不是直接用实际间隔：

- 直接用实际间隔会**奖励拖延**：拖三个月再答对，下下次就排九个月。
- 完全不认逾期会**惩罚诚实**：用户出差两周，回来答对却和不复习一样。
- 折半后，逾期答对明显好于准时答对，但不会一次把卡送到"掌握"。

逾期补偿只作用于 `CORRECT`。`PENDING` / `WRONG` 仍按上表回退——
「拖了很久还是不会」是更强的遗忘证据，不该被时间补偿。

### 4.2 难度漂移

```
D ← clamp(D + 0.35×(4 - grade), 1, 10)     grade: 0=wrong 2=pending 4=correct
PENDING / WRONG 时 D 上升，CORRECT 时不变
```

**答对不改变 D**（grade=4 → 0.35×0 = 0）。速度不再分档，
所以也没有「快答降 D」——答题用时不再作为难度信号。

> **D17 修正**：本文原写 `D + 0.35×(grade-4)`，那会让**答对把 D 推高、
> 答错把 D 拉低**，与上一行注解、`ease_factor` 的定义、`§3` 表里
> 「D 越大间隔越短」的前提全部相反。符号按注解改为 `4 - grade`。
> 实测：WRONG 让 D 从 5.0 → 7.8（`ef` 1.02 → 0.68），方向正确。

### 4.3 会话数 vs 天

```
下次到期时间 = lastReview + 本次间隔（S_before × ease_factor(D)）
到期时间戳直接写进 card_state.due_at
```

**这是与规格 §6 最大的差别**：`S` 是真实天数间隔，
不是"练几场"。今天练 3 场不会让间隔变成 3 个单位。

会话内的"第几题"不参与排期计算，只影响**同一场内的重复**。

> **D17 修正**：不要在视图里现算 `last_review + stability*86400`。
> 排期用的是**答对前**的 S（`S_before × ef`），而 `stability` 存的是
> **答对后**的 S（`× (1+ef)`），两者差一个 `(1+ef)` 倍。
> 主义 s1 首答：引擎说 2.04 天，视图算 4.08 天 —— 实际到期比提示晚近一倍。
> 因此 `due_at` 单列存，`v_due` 直接读它。

## 5. 场次排布

### 5.1 到期判定

```
due = (now >= lastReview + S×intervalFactor 天)
```

会话开始时取所有 `due` 的卡，按权重排序取前 N。

### 5.2 权重（同 `02-淘汰与替换.md` §5）

```
weight = 0.5 × 近30天WRONG率 + 0.3 × isTrap + 0.2 × (1 - 掌握度)
掌握度 = clamp(1 - (S / 180天), 0, 1)
```

`S` 越大越"掌握"。180 天是"完全掌握"的门槛。

### 5.3 兜底填充

到期卡不足时，按顺序补：

```
1. 生词库中的目标词
2. 未安排但 TRAP 的卡
3. 未安排但 S 最小的卡（最不稳的）
4. 任意 active 卡
```

---

## 6. 掌握判定

比规格 §6 更严，因为有了 `S` 作为客观依据：

```
MASTERED = (
    S >= 90 天
    AND reps >= 6
    AND 近 3 次有效作答全对
    AND 无 PENDING
)
```

**或**用户手动标记「我已学会」→ 立即 MASTERED，绕过全部条件。

> **`S >= 90 天` 是硬门槛。** 单纯"连续答对 3 次"在旧设计里
> 3 场会话就能达成（可能全在同一天），毫无记忆学意义。
> 要掌握一个义项，必须**真的隔了三个月还能读对**。

## 7. 特殊场景

### 7.1 长时间不练

```
若 lastReview 距今 > 3×S:
    标为 "rusty"          # 只标记，不改 S
```

`rusty` 的卡优先排入会话（久未复习的先捡回来），但不降 `D`（难还是难）。

> **2026-10-29 修正：衰减不再预扣 S。**
> 旧实现先 `S × 0.7` 再排期，等于默认「这么久没练，肯定忘了」。
> 但卡还没作答，任何结果都可能；而且逾期答对现在会按实际间隔补偿（§4.1.2），
> 先砍 S 会把「其实还记得」的证据提前毁掉。
> 让作答结果决定怎么写回 S：答对按逾期补偿，答错/不会照常回退。
> 真正要防的「学完就忘」由 `rusty` 标记 + 重新入队保证。

### 7.2 同一天内多次复习

```
若距上次复习 < 6 小时:
    S 增长乘以 0.5        # 同日重复收益减半
```

防止"一口气练 50 场"把 S 灌到虚高。

### 7.2.1 提前复习打折（2026-10-24 追加）

```
若没到期就答对（now < 上次排的 dueAt）:
    S 增长乘以 (已等待时间 / 计划间隔)     # 与同日减半叠加

若逾期才答对（now > 上次排的 dueAt）:
    有效间隔 = 计划间隔 + 0.5 × (实际间隔 - 计划间隔)
    下次间隔 = 有效间隔 × (1 + ef)          # 见 §4.1.2
```

动机：随机队列（首页"随便刷"）不看排期，一张卡一周内可能被反复刷到。
若提前答对也满额增长，连刷几天即可"速成掌握"（连对 3 次 + S≥90 + reps≥6
三个条件都不看日历跨度），这张卡从未经历长间隔考验就从所有队列消失——
等于允许偷懒。打折后刷得越早越不值钱，刚答完立刻再刷到 ≈ 零增长。

逾期补偿则是反方向：真的隔了很久才答对，应该比准时答对拿到更长的间隔，
但不能按实际时间全额奖励（否则奖励拖延），所以超出计划的部分只认一半。

配套：随机队列把 24 小时内答过的卡排到最后，优先出久未露面的；
池子不够时按 lastReview 从旧到新补足，队列不为空。

提前**答错**不打折——第 2 天想不起来，第 7 天更想不起来，照罚。

### 7.3 换词库 / 义项升级

SRS 状态挂在 `(word, senseId)` 上，**只在 `senseId` 稳定时迁移**
（同一词库内的增量升级，见 `02-淘汰与替换.md` §4.1）。
义项被 `archived` 时，其 SRS 记录一并归档，不参与排布。

> **D16 换源时不迁移。** 从考纲词频表换成 ECDICT 后 `senseId` 全部失效，
> 模糊匹配 68% 也不足以继承进度（旧义项 vs 新义项是不同的知识单元）。
> 新库 SRS 从 `S=0` 重新开始。

## 8. 诚实度约束

**复习正确率曲线**（规格 §6 已定，此处细化）：

- 只统计**到期**卡次的 `CORRECT / WRONG`；
- `PENDING` 计入分母不算分子（暴露"不会"的比例）；
- 主动提前复习的卡次**不计入**（否则自己刷熟悉的卡能刷出漂亮曲线）；
- 样本 < 20 显示"积累中"。

这条曲线是**唯一**的自检指标。若它长期在 85% 以上，
说明题太简单或排期太密，应主动调难度档而不是庆祝。

## 10. 与旧设计的差异对照

| 项 | 规格 §6（旧） | 本文 |
| --- | --- | --- |
| 间隔单位 | 会话数 | **天** |
| 状态量 | `interval` + `ease` | **`stability` + `difficulty`** |
| 增长 | 固定 ×2.0 | 按 D 变化的 `ease_factor` |
| 初始 | 全一样 | **按义项类型分 5 档，TRAP 最短** |
| 掌握 | `interval>=3` + 连对 3 次 | **`S>=90天` + reps>=6 + 连对 3** |
| 遗忘衰减 | 无 | 超过 3×S 标 `rusty`（不改 S，交给作答决定） |
| 同日重复 | 无惩罚 | 收益减半 |
| 曲线统计 | 到期卡的正确率 | 到期卡 + 排除提前复习 + PENDING 入分母 |
