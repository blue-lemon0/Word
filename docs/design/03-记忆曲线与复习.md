# 记忆曲线与复习排期

> 关联：规格 §6（旧 SRS，`interval`/`ease` 简单表）
> 本文**替换**规格 §6。理由见 §1。

---

## 1. 为什么不用现成的 SM-2

规格 v2.4 §6 用的表：

```
答对 → interval × 2.0, ease + 0.05
答错 → interval = 1,      ease - 0.1
```

三个问题：

| 问题 | 后果 |
| --- | --- |
| `interval` 单位是**会话数**，不是天 | 今天练 3 场 = 3 个单位；明天练 3 场 = 又 3 个。真实间隔在 3~24 小时内剧烈波动，算法却认为等价 |
| 二分区间无中间档 | 1→2→4→8→16 是 2 的幂，遗忘曲线是连续的，指数增长会**必然错过**最危险的 3~7 天窗口 |
| 只有一个 `ease`，无法区分"难词"与"熟词" | TRAP 义项（熟词僻义）和生词用同一套参数，实际难度差 3 倍以上 |

**但也不直接上 FSRS。** FSRS 需要每个词至少 10 次复习记录才有稳定参数，
而本项目是**义项级**训练卡，7884 张卡上平均每张只练 10-20 次 ——
刚好在数据量边缘，且用户要"个人自用、不做多因子调参"。

**决策：FSRS-lite —— 借用其核心洞察（难度与稳定度分离），但用可解释的固定参数。**

---

## 2. 状态模型

每张义项卡有四个状态量：

| 字段 | 含义 | 范围 | 初始 |
| --- | --- | --- | --- |
| `stability` (S) | 记忆稳定度：能撑多少天不复习 | 0.1 ~ 365 天 | 首次答对后由初始 S0 决定 |
| `difficulty` (D) | 固有难度：这个词对我有多难 | 1 ~ 10 | 由 S0 决定 |
| `lastReview` | 上次复习时间 | 时间戳 | - |
| `reps` | 复习次数 | 整数 | 0 |

**关键点：`S` 和 `D` 分离。**
`D` 描述"这个词本身难"（几乎不变），`S` 描述"我目前记得多牢"（每次复习都变）。
这正是 FSRS 的核心洞察，比单一 `ease` 强。

---

## 3. 初始参数（S0 / D0）

按**义项类型**给不同初值，而不是所有人一个起点：

| 义项类型 | S0（天） | D0 | 理由 |
| --- | --- | --- | --- |
| 生词首次出现 | 0.6 | 8.0 | 极不稳，需要密集复习 |
| CORE 单义词 | 1.2 | 6.0 | 见过但没熟 |
| CORE 多义词 s1（主义） | 2.0 | 5.0 | 最熟悉 |
| CORE 多义词 s2+（**TRAP**） | 0.8 | 7.0 | 看起来会读，实际读错 |
| 低频词 / 低 tier | 0.5 | 8.5 | 几乎没印象 |

> **TRAP 给最短 S0 是本设计最重要的一条**。
> 用户的真实痛点是"abandon 我认识，但看不出是『使屈从』还是『遗弃』"，
> 所以 TRAP 卡必须**比其他卡更早、更频繁地出现**，直到读准为止。

## 4. 复习间隔

```
下一次复习间隔（天）= S × 间隔因子 × 当日场次修正
```

### 4.1 间隔因子

用 `ease_factor(D)` 代替固定倍数，让**难词增长更慢**：

```
ease_factor(D) = 1.50 - 0.12 × (D - 1)      clamp 到 [0.35, 1.50]

  D=1  → 1.50    最简单的词，长得最快
  D=3  → 1.26
  D=5  → 1.02
  D=7  → 0.78
  D=10 → 0.42    最难的词，长得最慢
```

整段无 clamp 截断（只在越界时生效），保证 **D 越大间隔单调越短**。
若把上限压到 1.4，D=1 与 D=3 都会落在 1.4，难度信号被抹平——
这是早期参数的错误，已修正。

| 当次结果 | grade | S 变化 | 到期天数 |
| --- | --- | --- | --- |
| `CORRECT` 快（< 该难度档基准时间） | 5 | `S × (1 + ease_factor(D))` | `S × ease_factor(D)` |
| `CORRECT` 慢 | 4 | `S × (1 + ease_factor(D) × 0.7)` | `S × ease_factor(D) × 0.7` |
| `PENDING`（点不会/超时） | 2 | `S × 0.8` | `S` |
| `WRONG` | 0 | `max(0.3, S × 0.4)` | `0.4 × S` 天（至少 2 小时后再现） |

> `WRONG` 后 `D += 0.8`，下次 `ease_factor` 自动变低，
> 增长自然放缓——不需要额外的惩罚规则。

**间隔下界**：任何情况下到期天数 ≥ 0.25 天（6 小时），
否则一口气连练会把当天所有卡刷成"已到期"。

### 4.1.1 实际推演（`scripts/verify_srs.py` 实跑，非手算）

以 §3 的四类初值起步，各答对 4 次（均快），看到期间隔演化（天）：

| 类型 | S0/D0 | 第1次 | 第2次 | 第3次 | 第4次 |
| --- | --- | --- | --- | --- | --- |
| 主义 s1（D=5） | 2.0 | 2.0 | 4.1 | 8.3 | 16.8 |
| 单义（D=6） | 1.2 | 1.1 | 2.1 | 3.9 | 7.4 |
| TRAP（D=7） | 0.8 | 0.6 | 1.1 | 2.0 | 3.5 |
| 新词（D=8） | 0.6 | 0.4 | 0.7 | 1.1 | 1.8 |

**s1 与 TRAP 的比值随复习次数拉开**：2.8x → 3.2x → 3.7x → 4.2x。
即熟词僻义卡会稳定落在主义卡约 1/3 的间隔上，
这正是设计意图：TRAP 更早、更频繁地重现。

**达到 90 天掌握门槛所需的连对次数**：

| 类型 | 需连对 | 到达 S |
| --- | --- | --- |
| 主义 s1 | 6 次 | 136 天 |
| 单义 | 7 次 | 107 天 |
| TRAP | 9 次 | 144 天 |
| 新词 | 10 次 | 95 天 |

> 新的义项要 6-10 次正确才可能"掌握"。这看起来多，
> 但因为间隔是**天**不是"场次"，一个义项跨越 3 个月练 7 次是正常节奏。
> 旧设计（连对 3 次即掌握）可以在同一天内达成，毫无记忆学意义。

### 4.2 难度漂移

```
D ← clamp(D + 0.35×(grade - 4), 1, 10)     grade: 0=wrong 2=pending 5=fast 4=slow
WRONG  时 D 上升，FAST 时 D 下降
```

**慢速答对也算负反馈**（grade=4 → 0.35×0 = 0），不惩罚不奖励。

### 4.3 会话数 vs 天

```
下次到期时间 = lastReview + S 天
```

**这是与规格 §6 最大的差别**：`S` 是真实天数间隔，
不是"练几场"。今天练 3 场不会让间隔变成 3 个单位。

会话内的"第几题"不参与排期计算，只影响**同一场内的重复**。

## 5. 场次排布

### 5.1 到期判定

```
due = (now >= lastReview + S×intervalFactor 天)
```

会话开始时取所有 `due` 的卡，按权重排序取前 N。

### 5.2 权重（同 `02-淘汰与替换.md` §5）

```
weight = 0.5 × 近30天WRONG率 + 0.3 × isTrap + 0.2 × (1 - 掌握度)
掌握度 = clamp(1 - (S / 180天), 0, 1)
```

`S` 越大越"掌握"。180 天是"完全掌握"的门槛。

### 5.3 兜底填充

到期卡不足时，按顺序补：

```
1. 生词库中的目标词
2. 未安排但 TRAP 的卡
3. 未安排但 S 最小的卡（最不稳的）
4. 任意 active 卡
```

---

## 6. 掌握判定

比规格 §6 更严，因为有了 `S` 作为客观依据：

```
MASTERED = (
    S >= 90 天
    AND reps >= 6
    AND 近 3 次有效作答全对
    AND 无 PENDING
)
```

**或**用户手动标记「我已学会」→ 立即 MASTERED，绕过全部条件。

> **`S >= 90 天` 是硬门槛。** 单纯"连续答对 3 次"在旧设计里
> 3 场会话就能达成（可能全在同一天），毫无记忆学意义。
> 要掌握一个义项，必须**真的隔了三个月还能读对**。

## 7. 特殊场景

### 7.1 长时间不练

```
若 lastReview 距今 > 3×S:
    S ← S × 0.7          # 衰减
    标为 "rusty"
```

`rusty` 的卡优先排入会话（久未复习的先捡回来），
但不降 `D`（难还是难）。

### 7.2 同一天内多次复习

```
若距上次复习 < 6 小时:
    S 增长乘以 0.5        # 同日重复收益减半
```

防止"一口气练 50 场"把 S 灌到虚高。

### 7.3 换词库 / 义项升级

SRS 状态挂在 `(word, senseId)` 上，**只在 `senseId` 稳定时迁移**
（同一词库内的增量升级，见 `02-淘汰与替换.md` §4.1）。
义项被 `archived` 时，其 SRS 记录一并归档，不参与排布。

> **D16 换源时不迁移。** 从考纲词频表换成 ECDICT 后 `senseId` 全部失效，
> 模糊匹配 68% 也不足以继承进度（旧义项 vs 新义项是不同的知识单元）。
> 新库 SRS 从 `S=0` 重新开始。

## 8. 诚实度约束

**复习正确率曲线**（规格 §6 已定，此处细化）：

- 只统计**到期**卡次的 `CORRECT / WRONG`；
- `PENDING` 计入分母不算分子（暴露"不会"的比例）；
- 主动提前复习的卡次**不计入**（否则自己刷熟悉的卡能刷出漂亮曲线）；
- 样本 < 20 显示"积累中"。

这条曲线是**唯一**的自检指标。若它长期在 85% 以上，
说明题太简单或排期太密，应主动调难度档而不是庆祝。

## 10. 与旧设计的差异对照

| 项 | 规格 §6（旧） | 本文 |
| --- | --- | --- |
| 间隔单位 | 会话数 | **天** |
| 状态量 | `interval` + `ease` | **`stability` + `difficulty`** |
| 增长 | 固定 ×2.0 | 按 D 变化的 `ease_factor` |
| 初始 | 全一样 | **按义项类型分 5 档，TRAP 最短** |
| 掌握 | `interval>=3` + 连对 3 次 | **`S>=90天` + reps>=6 + 连对 3** |
| 遗忘衰减 | 无 | 超过 3×S 衰减，标 `rusty` |
| 同日重复 | 无惩罚 | 收益减半 |
| 曲线统计 | 到期卡的正确率 | 到期卡 + 排除提前复习 + PENDING 入分母 |
