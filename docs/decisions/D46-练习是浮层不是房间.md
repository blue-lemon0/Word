# D46 —— 练习是浮层，不是房间；首页内部有可横滑的副页

> 决策日期：2026-10-19
> 一句话：**练一句话不该把整屏交出去；一屏放不下的状态，用滑的。**

---

## 一、单挑为什么「太深太孤单」

原来的「练这一句」是一个**页面**：

```
首页/扫读 ──点击──> 整屏单题（顶栏、进度、答题、解释、结算）
             ←──返回── 还得再点一次才回得去
```

为了练一句话，要付出：一次转场 + 一次状态恢复 + 一次返回。而且那个页面
天生空（一道题撑不起一整屏），于是「深」和「空」同时出现。

**判据**：练一句话，多久能回到原来的地方？页面模式是「关掉再回来」，
浮层模式是「关掉就在原地」。

## 二、现在是浮层（`DrillSheet.vue`）

```
        （首页信息流 / 扫读列表还在后面，不跳页）

  ┌─────────────────────────────────┐
  │ resilient  adj. /rɪˈzɪliənt/     │
  │ This mattress is made of a ...   │
  │  [A] [B] [C] [D]                 │
  │  错了 · 下次 今天内               │
  │  中文 + 正解 + 同义例句            │
  │  [继续扫]         [再练一次]      │
  └─────────────────────────────────┘
```

- **判分链路与训练页完全一致**（`makeQuestion` → `recordAnswer`），
  所以 SRS、连对、错题率都是同一套 —— 浮层不是「另一个迷你练习」。
- 关掉就回原地；`close-on-popstate` 让系统返回键也能关它。
- `/train?solo=` 只留给**错题板深链**（从别的页面跳过来的那条路，本来就需要一整屏）。

## 三、首页内部再分「副页」（横滑）

一屏给不了四种状态，但**滑一下**就能。首页现在是 `van-tabs` + `swipeable`：

| 副页 | 内容 | 通向 |
|---|---|---|
| 今天 | 信息流：今天一行 + 快捷卡 + 随手背一句 + 最近在练 | 各自的目标 |
| 在学 N | 练过、还没掌握的**词表**（带 练过 x/y） | 点行进词条；「练这组」进 `?scope=learning` |
| 待学 N | 一次都没练过的词表 | 点行进词条；「学几个」进 `?scope=new` |

三页的数字和词库页的五个桶**同一套口径**（按词数、按最紧要的义项归类）。

踩到的坑：Vant 给 `.van-tabs__wrap` 写死了 `height: 44px`，
往里面加 `padding-top` 会把标签挤出盒子、裁在状态栏底下 ——
必须同时 `height: auto`；顶部让位用 `--wb-sb-h`（和 `.wb-topbar` 同一套），
不能直接写 `env(safe-area-inset-top)`（WebView 里常常是 0）。

## 四、判据

| 断言 | 拦的是什么 |
|---|---|
| 练一句是浮层（`DrillSheet` + `recordAnswer` + `makeQuestion`） | 另写一个迷你练习，SRS 两套 |
| 首页有可横滑的副页（`swipeable` + 三个 tab） | 又退回「一屏一竖列」 |
| 扫读点句 → 开浮层（不 `replace` 路由） | 练一句又把整屏换掉 |
