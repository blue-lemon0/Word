# D50 —— 首页两屏定稿：一屏刷，一屏看句子；背单词页留着

> 决策日期：2026-10-19
> 一句话：**屏一随机刷（独立），屏二句子列表 + 两颗入口按钮，正式练回背单词页。**

---

## 一、走过的一段弯路（记下来，别再走）

这一轮首页改了五版，前四版都被否掉。值得记的是「为什么会走偏」：

| 版本 | 形态 | 为什么不对 |
|---|---|---|
| v1 | 信息流（今天一行 + 快捷卡 + 随手背 + 最近在练） | 「一堆不需要的功能」；句子列表被藏进训练页底部 |
| v2 | 四个副页（今天/在学/待学/练），内部可横滑 | 副页之间重复词库的信息；「练」副页等于把训练页抄了一遍 |
| v3 | 两屏，屏一一屏一卡「点一下看意思」 | 只是「看」，不是「练」——背单词页的四选项/判分才是主体 |
| v4 | 两屏，屏一**随机 + 按计划**两种来源 | 屏一被塞了两种语义；点「复习/学习」滑回屏一，感觉不像「进入一轮复习」 |
| **v5（定稿）** | 屏一**纯随机**（独立），屏二句子列表 + 「复习 / 学习」→ **背单词页** | — |

**教训**：用户说「拆到副页」时，指的是**功能**（我不会、有问题？改、点词查义），
不是把整页 UI 搬过去重做一个更浅的版本。**主战场（一整轮练习）不要重造。**

---

## 二、定稿长什么样

### 屏一 · 随机（独立）

- 一题一屏，**竖向吸附滚动**（原生动画，上下滑换题；左右滑换屏）
- 题面复用 `QuestionBox`：词 + 音标 + 例句 + 四选项 + 判分 + 解析
- 出题源**只有随机**：`buildRandomQueue(50)`，不看到期、不参与复习计划、有「换一批」
- 底部**固定**两条：
  - `我不会` / `显示选项`（作答后变 `下一题`）
  - 作答后追加 `改例句` / `改释义`（同一个 `QuickEdit`）
- 作答后句子里的词可点 → 查义浮层（看整页 / 加词 / 排进明天）

### 屏二 · 句子（新闻 app 那样一列）

- 主体是 `ScanList`（随机句子列表，和背单词页底部同一份组件）
- 点一行 → 先看「这句什么意思」→ 想练就「练这一句」（浮层）
- 底部左右两颗：
  - `复习 · 今天剩余 N` → `/train?scope=due`
  - `学习 · 词库 M` → `/train?scope=new`

### 背单词页（`/train`）· 保留

一整轮 20 题、进度格可点回看、上一题/下一题、结算、就地改内容、AI 换句、
错题板单挑深链 —— 这些「一轮」才成立的体验留在这一页，首页不复制它。

---

## 三、两条硬规矩

1. **首页屏一 = 随机，独立**。它不读计划、不写计划；「复习/学习」是另一次进入。
2. **返回要回到原来那一屏**。`KeepAlive` 只缓存组件，滚动位置要自己在
   `onActivated` 里放回去（坑 62）。

## 四、判据

| 断言 | 拦的是什么 |
|---|---|
| 屏一只有随机（`buildRandomQueue`，不含 `buildScopeQueue`） | 又把两种来源塞回屏一 |
| 两屏横滑 + 屏一竖向吸附 | 滑动没动画 / 只能整页切 |
| 屏二两颗按钮带 `scope` 打 `/train` | 点复习变成原地换一批 |
| 题面只有一份 `QuestionBox` | 又抄一个练习实现 |
