# D36 —— 训练是一个动作，不是一个地方

> 决策日期：2026-10-19
> 一句话：**底栏只放「地方」；「训练」从首页进、盖满全屏、有返回。**
> 连带三件同源的事：扫读并成训练页下面的一节、发现内容错要能当场改、
> 干扰项只按词性挑且同词优先。

---

## 一、训练退出底栏

### 现象

底栏四项是「首页 / 词库 / 训练 / 更多」。前三项和第四项都是**地方**
（可以停在那儿、可以从里面再钻进去），训练不是 ——
点进去就是一道题接一道题，走完一轮就结束。

更直接的证据是扫读：它当时是 `mode === 'scan'`，**独占整屏**。
从首页进扫读，训练入口就被顶掉了 —— 用户看到的是「另一个页面」，
想回去还得先想起「返回在哪」。一个占满屏、有自己返回栈的东西
摆在「同级的地方」里，是这个分类错的。

### 为什么底栏出现在这里就是错的（真问题）

底栏在手机上被读成「**和我同级的几个地方**」。把一个动作摆进去，
同时产生两种错误预期：

| 预期 | 实际 |
|---|---|
| 「训练」是第四个可以去的地方 | 它是一段一次性的过程 |
| 在训练页点别的 tab = 换个地方 | 压一层历史，返回键退回半路的题 |

和 D35 的「二级页不摆底栏」是**同一条原则**：界面结构该由
「用户以为这是什么」决定，不由「控件长什么样」决定。

### 做法

- 底栏只留三个 tab：**首页 / 词库 / 更多**。路由表里只有这三条声明
  `meta: { tab: true }`。
- 判断改成 **默认隐藏、显式声明**：`showTabs = route.meta.tab === true`。
  原来是一张手维护的「要隐藏的前缀表」（`/word/ /sense/ /board`），
  它的失败模式是**静默**的 —— 加了 `/scan` 却忘了加进那张表，
  扫读页就顶着底栏出现，没人报错、没人察觉。
  反过来写，新增页面**默认就是子页**，漏写的后果从「悄悄露出底栏」
  变成「新 tab 页少一行声明」，代价落在开发侧而不是用户侧。
- 训练因此必须自己给自己一条退出路径：顶栏返回箭头（等同系统返回键）。
- 「按计划」没有到期项时**置灰**，原因写在 hint 里。
  比「点进去 → 组出空队列 → 跳去另一种练法 → 弹一句看不懂的提示」
  好在**代价前置**：不点就不会被丢到别处。

### 放弃了什么

训练页里不再能一键去别的 tab。代价是「练完想去词库」要多按一次返回。
换来的是后退栈一条线，以及「训练」这个动作不再被读成第四个地方。

## 二、扫读从「第三个页面」变成训练页下面的一节

### 现象

扫读原本是一个整屏的练法（`mode === 'scan'`）：进扫读就把
「今天练什么」顶掉，看着像另一个页面。

### 做法

- 抽成 `ScanList.vue` 组件，作为**训练页下面的一节**：
  滚一屏能同时看到「今天练什么」和「随手扫两句」，不用两个整屏来回切。
- 「换一批」放**标题行**，不放列表末尾。放末尾时它的位置 = 列表高度，
  行数一变按钮就上下跳，手指正要按的位置已经不是按钮了（真机反馈：刷新时按钮会抖）。
- 行号与句子**共用同一个行高** + 顶部对齐，不用 `baseline`
  —— `.tx` 是组件，基线取决于它内部第一个行盒落在哪，
  包一层 block 之后基线就不是第一行文字的基线了（坑 55 的现场）。
- 行内**不挂词性标签**：真实语料里的句子不长那样，挂了就成了
  「词典 app 的句子」。要查词性点进单题，那里本来就有。

## 三、发现内容错，要能当场改

### 现象

发现某句例句或某个释义不对时，只有「记一句有问题」这一条路。
把人送去「词库 → 意思」页改，等于让他自己把那个句子重新找回来 ——
找不回来，于是坏内容一直坏下去。

### 做法

- 训练页一个入口：**「有问题？改」**。它只列**属于这道题的内容**：
  这一句例句、本题正确答案的释义。
- 入口**不挑时机**：答题前也能改。坏内容不该先把你考一次才轮到你修它。
- 改完**立刻回到原题**，并且题目内容**每次从库里重建**。
  「改完回到原题」是因为「看得见才敢信存上了」；
  「从库里重建」是因为内存里那个对象改完就是旧的，
  「明明存上了，回头一看还是错的」比不能改更劝退人。
- 训练页被 `<KeepAlive>` 留着（跳去意思详情/词条「核验」再回来，
  这一轮做了一半的题还在）。别的页面一律不缓存 ——
  词库、意思页都是「改了要马上看到」的地方。
- 选项**不给改**：跨词借来的改了等于改另一张卡片，
  同词借来的改了等于在你不看着的那张卡上动手。
  一道题的凑数选项不该有能力破坏别人的数据。
- 「改」和「核」是两件事：改 = 我确定错了（原地改）；
  核 = 我想看看（跳详情，原样回来）。两个都要有。

## 四、干扰项：只按词性挑，同词优先

题目问的是「这个词在这句话里是什么意思」，所以：

- 干扰项**只要求同一个词性**。不要求词性对得上，四个选项就出现
  「名词释义 vs 动词释义」的区别，用户能靠词性排除蒙对 ——
  那是换了一种作弊方式。
- **同一个词的别的义项优先占两个位**。跨词的干扰项「一眼就看出不是这个词的意思」，
  四个字扫一下就划掉，练不到东西；同词义项**都像**正确答案，
  只能靠「这句话到底是哪个意思」区分 —— 那才是这道题要练的能力。
  句子已经把义项钉死了，所以它们不是第二个正确答案，是**贴着答案的干扰**。
- 兜底：词性都不够时宁可词性不齐，也不能凑不满四个选项。

## 五、判据与真机验证

机械判据（`scripts/verify_docs.py`「真机交互守卫」）：

| 断言 | 拦的是什么 |
|---|---|
| 训练不再是 tab（路由表里没有 `meta.tab`） | 只改渲染处、没改声明处（或反过来） |
| 底栏只画三项（没有训练） | `meta.tab` 只控制整条栏显不显示，**不会过滤栏里的项** |
| 恰好三个路由声明了 `meta.tab` | 加 tab 时忘了补声明 |
| 训练页有返回箭头 | 不再是 tab 就得自己给退出路径 |
| 「按计划」没得练时置灰 | 点进去才发现是空的 |
| 作答状态压过呈现状态（坑 54） | 「我不会」之后卡死 |
| 扫读是训练页下面的一节 | 又冒出一个整屏练法 |
| 扫读「换一批」在标题行 | 按钮随列表长度上下抖 |
| 扫读行两列共用行高 | 对齐靠猜 |
| 训练时能当场改内容 / 改完回到原题 | 改入口写了但没接上 |
| 干扰项只取同词性 / 同词义项更常被抽中 | 干扰项规则悄悄退化 |
| 训练页能被 keep-alive 留着 | 跳去核验一次丢掉一轮 |

行为判据（`app/web/tests/flow_smoke.mjs`）：
干扰项全部同词性、同词义项真的更常出现、选项不重复且含正解。

真机：底栏三项；`/train` 无底栏、有返回箭头；训练页往下滚就是扫读；
扫读行号与句子首行齐平。
