# D44 —— 首页 = 随手背一句（随机背诵）

> 决策日期：2026-10-19
> 一句话：**打开 app 就能背一句**，而不是先看一张海报、再决定要不要跳进训练。

---

## 一、首页的三次变形

| 版本 | 首页是什么 | 为什么不够 |
|---|---|---|
| v1 | 搜索框 + 一个随机词 + 去训练 | 搜索抢了主线；点例句里的词会**跳页**，把这张卡顶掉 |
| v2 | 随机词 + 看统计的卡片 + 去训练 | 卡片**只能看不能背**；统计卡和「去训练」两个入口通往同一件事 |
| v3（现在） | **能背的卡**：点一下看意思 + 换一个 / 练这一句 / 去复习 | — |

判据很简单：**碎片时间打开它，能不能直接开始背？**
v2 的答案是「不能，得先跳一次」；跳过三次之后，人就只在「今天有到期」时才打开它了。

## 二、现在的首页长什么样

```
        nuance
        /ˈnjuːɑːns/

   We should consider every aspect of the problem.

        [ 点一下看意思 ]

  ┌──────────────────────────────┐
  │ n.  方面；面貌                │
  │ 我们应该考虑这个问题的每个方面。│
  └──────────────────────────────┘

  [ 换一个 ]        [ 练这一句 ]
  [      去复习 · 今天 3 题到期      ]
```

- **点一下看意思**：卡上直接给这一句的答案（词性 + 释义 + 中文 + 备注）。
  这是首页唯一的核心动作 —— 能背，才叫首页。
- **换一个**：抽下一张（统计一起刷新），答案自动收起。
- **练这一句**：进训练页的单句练（只有这一句，有解析区、有返回，见 D43）。
- **去复习**：唯一的「进训练」入口，副标题写着今天有多少到期。

## 三、顺手删掉的三样东西

1. **搜索框**：词库页已经有同一个搜索；首页再放一个是「两个入口做一件事」。
   而且它跳的是词条页，而真正的查词发生在**阅读/练习的现场**（那里有浮层）。
2. **整块可点的统计卡**：它和「去训练」同一去处。一屏两个入口通往同一件事，
   点哪个都行，反而让人以为它们不同。统计降级成「去复习」按钮的一行副标题。
3. **例句点词就跳页**：改成开**浮层**（和训练页同一个 `WordPeek`）。
   想顺藤摸瓜看一眼，不该把首页这张卡顶掉；浮层里还能「看整页」或「加入词库」——
   和训练页同一套行为，不再是「只弹一句 toast」。

## 四、判据

| 断言 | 拦的是什么 |
|---|---|
| 卡上有「点一下看意思」 | 首页退化成海报（能看不能背） |
| 首页没有搜索框 | 两个入口做一件事又回来了 |
| 通往训练的入口只有一个 | 一屏两个「去训练」 |
| 例句点词开浮层（`WordPeek`） | 点个词就跳走、丢掉这张卡 |
