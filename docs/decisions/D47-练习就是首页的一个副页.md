# D47 —— 练习就是首页的一个副页

> 决策日期：2026-10-19
> 一句话：**「去训练」这个词应该消失** —— 打开首页就能练，练完还在首页。

---

## 一、问题：「花了这么多功夫，练习还是那么深」

D46 把「练这一句」做成了浮层，但**成组的练习**（今天复习 / 学新词 / 在学再刷）
仍然跳 `/train` 一整页。于是路径还是：

```
首页 ──点快捷卡──> 训练页（选练法 → 答题 → 结算）──返回──> 首页
```

这就是「我们不是想让练习成为首页的副页吗」的那口气。

## 二、现在：第 4 个副页「练」

首页的 tab 变成四个，滑一下就到：

| 副页 | 内容 |
|---|---|
| 今天 | 信息流 |
| 在学 N | 词表 |
| 待学 N | 词表 |
| **练** | **就地练：题干 + 选项 + 判分 + 解析 + 下一题** |

- 快捷卡（今天复习 / 学新词 / 在学）**不再跳页**，而是把队列装进「练」副页并切过去；
- 队列仍然走 `buildScopeQueue`（和词库「练这组」同一条口径）；
- 题目渲染走 `QuestionBox`（和浮层、训练页共用一份）—— 判分链路一致；
- 练完留在这一页，可以「再来一组」。

`/train` 仍然存在，但它的定位变了：**深练**（回看、跳题、改内容、AI 换句、
单挑深链）才去那里。日常背两句，不用离开首页。

## 三、顺手修的三处

1. **「今天没有到期的」≠「今天没练」**。首页现在写「今天 14 个意思练过」，
   把**练了没有**和**到期没有**分成两件事说 —— 刚练完十几个的人不该读到
   「什么也没发生」。
2. **整页横滑切副页**。之前只有 `van-tabs` 的 `swipeable`，而副页里是长列表，
   纵向滚动会吃掉横向手势 ——「在学页下半部分滑不动」。现在在页面根节点自己判：
   横向位移 > 60px 且明显大于纵向才切页，其余一律放行给滚动。
3. **浮层高度固定 76vh**。原来是内容撑高，答完题之后高度一跳，正要点「再练一次」
   的按钮会跑掉。定高 + 内部滚动，第一次打开和答完之后是同一个盒子。

## 四、判据

| 断言 | 拦的是什么 |
|---|---|
| 首页快捷卡就地开练（`startPractice`，不跳 `/train`） | 又回到「跳页」 |
| 题目本体只有一份（`QuestionBox`：`makeQuestion` + `recordAnswer`） | 再抄一份迷你练习 |
| 首页四个副页（`<van-tab` ≥ 4） | 副页退化 |
| 浮层高度固定（`height: 76vh`） | 高度随内容跳 |

真机：首页点「12 学新词」→ 直接落在「练」副页出题（URL 没变）；
答完 → 下一题；右滑 → 待学。
