# D51 —— 冗余判定标准：什么该删

> 决策日期：2026-10-19
> 一句话：**给过答案的地方不再出题；为 0 的按钮不跳转；一个动作只留一个入口；一页只管一件事。**

这一轮删了十几处入口（净减几百行），都是靠下面四条判出来的。以后加功能先过一遍。

---

## 一、四条标准

### 1. 给过答案的地方，不设答题入口

**判据**：一个界面如果已经显示了 `词 + 释义`（或中文翻译），就不该再出现
「练这个 / 猜这个」的按钮 —— 那不是练习，是送分。

被这条删掉的：
- 句子浮层里的「练这一句」（上面刚给出释义和中文）
- 错题板每行的「单挑这个意思」（行内写着词和释义）
- 训练页的「怎么练」选择器（练法已经在首页选过了）

**例外**：首页屏一（随机）、首页屏二的两颗按钮、词库「练这组」——
它们的共同点是**抽到哪个词是未知的**，猜才有意义。

### 2. 数量为 0 的按钮，不许跳转

**判据**：按钮上写着数字，就该在数字为 0 时**置灰或换文案**，而不是照旧跳过去，
让人进去看一个空队列。

- 首页「复习 · 今天剩余 0」→ 置灰 + 文案变「今天没有到期的」
- 错题板「去训练」→ 改成「去复习」并带来期 scope（否则落进空队列）
- 词库「练这组」→ 桶里 0 个词时根本不渲染按钮

### 3. 同一个动作只留一个入口

**判据**：列出这个动作现在有几个入口，多于一个就问「删哪个」。

| 动作 | 唯一入口 | 删掉的重复 |
|---|---|---|
| 随机练 | 首页屏一 | 训练页的「随便练」、词库的「随便练两句」 |
| 看句子 | 首页屏二 | 训练页底部的扫读列表 |
| 正式一轮（复习/学习） | 首页屏二的两颗按钮、词库「练这组」 | 训练页的「怎么练」选择 |
| AI 体检 | 更多 → AI 体检 | 词库「维护」里的同名入口 |

### 4. 一个页面只管一件事

- 背单词页（`/train`）：只管**一整轮**（进度格、回看、跳题、改内容）。不做选练法、不做扫读。
- 首页屏一：只管**随机刷**。不读复习计划、不写计划。
- 首页屏二：只管**看句子 + 两个入口**。
- 词库：只管**管理**（五个桶、搜索、维护）。
- 错题板：只管**看清单**。

---

## 二、加功能前的自查四句

1. 这个界面上是不是已经给出答案了？给了就别再出题。
2. 这个按钮点下去，有没有可能进去是空的？会，就置灰。
3. 这个动作别的页面是不是已经能做了？能，就别加第二个。
4. 这一页现在负责几件事？超过一件，考虑拆或挪。

## 三、机械判据（守卫）

| 断言 | 拦的是什么 |
|---|---|
| 句子浮层没有「练这一句」、首页不接 `@drill` | 看答案后又让猜 |
| 错题板没有「单挑」、不链 `/train?solo` | 同上 |
| 首页「复习」在 0 时 `:disabled` | 0 数量还跳转 |
| `buildRandomQueue` 只出现在首页 | 随机入口又变成两个 |
| 背单词页不再 import `ModePicker` / `ScanList` | 一页管两件事的老路 |
