# D52 —— 背完一轮之后，可选「拼一遍」

> 决策日期：2026-10-19
> 一句话：**认出 ≠ 写出。** 一轮背完之后给一个可选加练：看中文，把英文写出来。

---

## 一、为什么放在「一轮结束之后」

- 拼写比认义项慢得多（要打字），不适合夹在一轮 20 题中间；
- 刚背过的那一批词就在手边（`lastRound`），趁热拼才有意义；
- **可选**：不想要的人点一下「回首页」就走了，不阻塞主流程。

## 二、它和 SRS 的关系：**不写**

拼写考的是「产出」记忆，认义项考的是「辨认」记忆。把拼写的对错喂给间隔算法，
会污染「这个意思我到不到期」的判断 —— 所以：

- 拼写**不写 `progress`、不写 `reviewLog`**；
- 只在这页给一份自己的小结（拼对几个 / 写错哪几个）；
- 想让它影响排期？那得先有「拼写正确率」这个独立维度，等以后再说。

守卫盯着这一条：`TrainPage` 里 `recordAnswer(` 只出现 **1 次**（答题那条路）。

## 三、交互细节

```
拼写  3 / 20                                     结束
┌────────────────────────────────┐
│ n.                             │
│ 能力，本领（做某事的能力）        │   ← 只给中文 + 词性
└────────────────────────────────┘
┌────────────────────────────────┐
│ 写出英文                        │   ← 大字号输入，自动聚焦
└────────────────────────────────┘
[ 提示 ]                     [ 对一下 ]

拼对：绿框 + 「对了」，0.55s 后自动下一题（快节奏）
拼错：红框 + 「正确答案：ability」 + [再试一次] [下一个]
```

- **提示**只给「首字母 + 字母数」（`首字母 a · 共 7 个字母`）—— 再多就等于给答案；
- 比对口径只有一处：`src/spell.ts` 的 `spellMatched`（忽略大小写 / 首尾空白 /
  词内多余空格），组件里不许再写一遍；
- 回车 = 对一下；答错后再回车 = 下一个；
- 结算：`拼对 X / Y` + 写错的词表（词 + 释义），可「再拼一遍 / 回到结算 / 回首页」。

## 三点五、错题循环：直到全对

「走到最后一个之后，如果前面有错的，自动跳回最早那个错的」—— 背单词和拼写都按这条走：

**背单词（`TrainPage`）**
- 维护一个 `wrongIdx`（还没答对的题号）；答对移出、答错/说不会留下；
- `next()` 分三条路：重练中 → 跳到 `wrongIdx` 里**最早的**那个；第一遍 → 顺序往后；
  第一遍到头 → 有错题就开重练（第 2 轮），全对才进结算；
- 顶部会显示「第 N 轮重练 · 还剩 K 个」；
- 跳到错题时会**清掉它上一次的作答快照**，让它重新出题（不是回看）。

**拼写（同一页的拼写相位）**
- 每一遍结束：`spellMissed` 里还有词 → 队列换成**只剩写错的那几个**，轮次 +1；
- 直到一遍里没有写错的，才进「拼写完成」；
- 头部显示「第 2 轮 · 1 / 3」。

**为什么不做「必须全对才能退出」**：手机上会被困住。任何一轮都可以按「结束」离开，
练习不该变成罚款。

## 四、判据

| 断言 | 拦的是什么 |
|---|---|
| 结算屏有「拼写这 N 个」入口（`spell-offer`） | 入口消失 |
| `recordAnswer(` 在 TrainPage 只出现一次 | 拼写偷偷写 SRS |
| 比对口径在 `src/spell.ts`，组件只调用 | 两处口径不一致 |
| 纯函数断言：大小写 / 首尾空白 / 词内空格 / 拼错 / 提示文案 | 比对退化 |
