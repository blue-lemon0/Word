# D54 —— 只发布 Android；iOS / 桌面 / 鸿蒙暂不投入

> 决策日期：2026-10-25
> 一句话：**正式分发只有 Android（签名 APK + AAB）。其他平台暂停，探索结论留档，重启前先读这一页。**

---

## 一、为什么停在这里

四个障碍，按重量级排：

| 障碍 | 代价 |
|---|---|
| 分发 | Apple Developer Program **$99/年** + App Store 审核；免费签名只能装 7 天，且**必须**有设备 |
| 构建 | 必须 macOS / Xcode。可借 GitHub Actions `macos-*`（公开仓库免费，私有仓库 10 倍分钟数） |
| 原生桥重写 | Swift 版 8 个接口：分享文件、分享文本、剪贴板、Toast、系统 TTS、Edge TTS WebSocket、HTTP POST、HTTP POST 二进制。等于把 `NativeBridge.java` 重写一遍 |
| 设备验证 | **没有 iPhone，无法验证** —— 用户明确指出的首要原因 |

## 二、探索结论（备查，不是待办）

### 1. iOS 不做原生壳，能做到什么程度

| 能力 | 裸 PWA（Safari 加主屏） | 加中转 | 说明 |
|---|---|---|---|
| 语音音质 | 只有系统 TTS（机械感） | ✅ 等价 | Edge TTS 服务端校验 Origin，浏览器改不了；从中转服务器发起就没有该限制 |
| AI 调用 | CORS 被拦 | ✅ 等价 | 同一招：中转转发，key 还可留在服务端 |
| 离线 | service worker 缓存 | ✅ 基本等价 | 首访须联网 |
| **存储** | ❌ **不保证** | ❌ 仍不保证 | 非主屏站点 7 天清理策略；主屏 app 通常不受限，但存储吃紧仍可能被回收，清 Safari 数据也会连带清。唯一兜底是导出备份 |
| 文件进出口 | 只能 `a[download]` / Web Share | 同 | 功能做得到，体验比原生绕；大包导入受 Safari 内存上限约束 |

结论：原生壳真正独占的只有 **系统级存储** 与 **免中转的语音**，其余差距可补。

### 2. 中转是 PWA 的必需项，不是可选项

- Edge TTS 校验 Origin → 浏览器直连必被拒
- 第三方 AI 不给 CORS 头 → 浏览器直连必被拦
- **预生成音频只覆盖存量**：用户新增单词、AI 换例句、AI 补全新句都是运行时产生的，包里不可能有音频。所以预生成只能是缓存优化，不能替代中转

### 3. 无设备时的验证路径

| 方式 | 成本 | 可信度 |
|---|---|---|
| Appetize.io（浏览器跑 iOS 模拟器） | 免费额度 | 模拟器，冒烟够用 |
| BrowserStack App Live / Sauce Labs | 免费试用分钟 | 真机 + 真 Safari |
| CI 里 `xcrun simctl` 起模拟器并截图 | 0 | 只来自动化截图比对 |
| 二手 iPhone SE 2 | 几百元一次买断 | 长期最省 |

## 三、边界（防「顺手多做一点」）

- 发版流水线（`.github/workflows/release.yml`）**只产出 Android**：`assembleRelease` + `bundleRelease`
- 不引入 Capacitor / Electron / Tauri / iOS 工程骨架
- Web 端保留的唯一用途是**开发调试**（`npm run dev`，`/tts` 与 `/ai` 的 vite 代理），不作为正式分发渠道
