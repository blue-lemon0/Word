# D37 —— 答完之后才许查词：句子里每个词都能点

> 决策日期：2026-10-19
> 一句话：**答题时不查词，答完随便查；查不到的词当场能收进词库（占位）。**

---

## 一、为什么必须「答完之后」

这道题问的就是「这个词在这句话里是什么意思」。答之前把词义摊开，
测的就不再是记忆，而是「你能不能忍住不看」—— 和 D36 里
「训练页不放错题板入口」是同一条规矩：**答案不该与题目同屏**。

所以这条不是「顺手加个功能」，而是一条**时序约束**：

| 时刻 | 句子里的词 |
|---|---|
| 没答 | 整句是死的（不可点），连「要不要查一下」的念头都不给 |
| 答完 | 每个词都能点：浮层里看义项、进详情、不在库里就加进来 |

判据写在两处、缺一不可：模板 `:pickable="submitted"`（决定句子长什么样），
处理函数 `if (!submitted.value) return`（挡住任何别的调用路径）。
只写其中一处，另一处就是漏洞。

## 二、点词 → 浮层，不是直接跳页

- 点一个词，多半只是想**扫一眼**。跳页会把人从这一题上带走，
  回来还得重新找回这道题（KeepAlive 保住了进度，但注意力没被保住）。
- 想细看时，浮层里给「看这个词的整页」和「点某一义项进它的详情」——
  跳转由 D36 的 keep-alive + `onActivated` 兜住：回来还在原题，内容是新的。
- 浮层里**先给条数**（「3 句」/「暂无例句」）：让人在点进去之前就知道
  那边有没有东西看，避免点进去看到一片空白。

## 三、查不到的词：当场加入，但只放占位

- 遇到生词、它又不在库里，这是人**最想把它记下来的那一瞬间**。
  让人退出训练 → 去词库页新建 → 再回来，实际结果就是不建。
- 所以浮层里给「加入词库：`<词形>`」，一步建出**词条 + 一个占位义项**。
  词形是词库里确认的原形；没命中时就是句中词形，绝不使用规则猜出来的候选。
- 占位义项必须标 `needsRefine = 1`：空白义项混进复习池就是一张
  永远学不会的卡。标了之后它出现在词库的「需精修」筛选里，
  下一步 AI 审查（`ai.reviewWord`）能直接把这一条补全。
- **不假装有内容**：浮层里就是「还没有释义」，不编一个释义出来。

## 四、形态还原：只采信词库里真有的候选

句子里是 `ordered` / `sides` / `studies`，词库存的是 `order` / `side` / `study`。
只按原样查会大面积落空，而落空在界面上长得像「词库缺这个词」。

规则很土：剥后缀（`s` / `es` / `ies` / `ed` / `ing` / `er` / `est` / `ly`）
+ 去双写（`stopped → stop`）+ 补 `e`（`making → make`），按可信度排序。

**关键约束：候选必须真的在词库里才被采用。** 于是规则猜错也不会把人
带到别的词上，最多是「没找到」—— 这比引进一份词形词典便宜得多，
也不用维护第二个真相源。

**没命中时保留原词形，不把候选写成原形。** 例如 `minister` 会命中
`er` 规则被剥成 `minist`，但 `minist` 不在词库里；此时浮层只说
「词库里没有 minister」，加入的也是 `minister`。否则一个不存在的
`minist` 会被当成事实写进词库，后续 AI 只会顺着它继续编。

`es` 那一条还有个顺序问题：`boxes` 该得 `box`（去 es），
`sides` 该得 `side`（只去 s）。判据是去掉 `es` 之后是否以 `s/x/z/ch/sh`
结尾 —— 是就用去 `es` 的候选，否则用去 `s` 的。

## 五、虚词不给「加入词库」

`the` / `of` / `was` 这些仍然可以点（否则句子千疮百孔），
但浮层里只说「虚词，一般不用单独记」，不给加入入口 ——
否则词库里会多出一堆永远不学的垃圾词条。

## 六、判据

机械断言（`scripts/verify_docs.py`「真机交互守卫」）：

| 断言 | 拦的是什么 |
|---|---|
| 查词只在作答之后 | `pickable` 绑错状态，或处理函数没挡 |
| 点词浮层能进详情、也能加入词库 | 浮层写了但少了某条路 |
| 顺手加入的词条是占位义项（`needsRefine=1`） | 空壳静默混进复习池 |
| 虚词不给加入入口 | 词库里长出 the / of |
| 形态还原只采信库里真有的候选 | 规则拼出来的词带偏用户（如 minister → minist） |

行为断言（`app/web/tests/flow_smoke.mjs`）：
`ordered/sides/studies/stopped/making/boxes` 的候选顺序、
原形命中、屈折形式命中原形、未入库不假装命中、未入库不猜原形
（`minister` 不变成 `minist`）、虚词识别、加入后立刻可查、
重复加入不建第二个、探针词清理。

真机：答完题后句子里点 `aspect` 出浮层（在库里、2 义项、带句数）；
点一个未入库的词给出「加入词库」。
