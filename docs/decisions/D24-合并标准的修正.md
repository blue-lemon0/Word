# D24 · 修正判断标准：合并的唯一合法依据是「是否同一个意思」

日期：2026-10
状态：**标准已修正，3 处已做错的要返工。** 现有数据一字未动。

## 我错在哪

我给外部 AI 的提示词里写了这么一条判断标准：

> 一条义项值得单独存在，当且仅当：**能造出 5 句英语例句，且每句都能与其他义项清楚区分。**

**这是概念错误。** 它把「学习者能不能学会」当成了「这个义项算不算存在」。

两句话在逻辑上不相关：

```
造句难 ≠ 同义        造句难只说明「例句要花更多功夫想」
同义   ≠ 造句难      同一概念在英文里本来就用不同搭配表达
```

## 修正后的标准

**一条义项值得单独存在，当且仅当它与同词其他义项指的是不同的概念。**

### 合法合并（同一概念的不同说法）

| 合并 | 为什么合法 |
|---|---|
| 版本 / 版 | 同一个词的两种中文叫法，指同一概念 |
| 答复 / 回答 | reply 英文只有一条边界，definition 只给一个义项 |
| 资本 = assets / wealth | WordNet 两个 synset 都指「资本」这一概念 |

判据是**语义本身**。可以问的问题：
- 这两个词在中文里能替换着用吗？→ 能，则同义
- 换成英文，两者的搭配集合相同吗？→ 相同，则同义

### 不合法合并（概念不同，只是共用词形）

| 不该合并 | 为什么 |
|---|---|
| 能力 / 才干 | 前者「能不能做」，后者强调「天赋、本领」。`he has the ability` vs `he has talent` |
| 切 / 执行 | 完全不同的概念。造句区分不了是因为词形共用，不是因为同义 |
| advantage 优势 / 好处 | 「固有条件上的优势」vs「某事件带来的好处」 |

## 两条真实后果

**① 我据此合并了 ability 的「才干」**

理由写的是「与 能力 语义重叠，英文两条边界不区分」。但：

```
he has the ability to solve it    他有能力解决
he has real talent for music      他有音乐天赋
```

主语结构不同、搭配不同、强调点不同——**这是两个义项**。我造不出 5 句是因为
我不够用心，不是这个义项不存在。要返工。

**② 我据此说 87 个高频动词的 WordNet 义项是「噪声」**

当时的理由是「造句区分不了」。看 `cut`：

```
cut.v.17  the act of cutting something into parts      切
cut.v.23  perform or carry out                         执行
```

这是**两个完全不同的概念**，只是共用 `cut` 这个词形（类似中文「他这个月开始
上夜班」里的「上」和「上个月」的「上」）。我错在把「词形共用」当成了「同义」。

## 连带要改的机制

`max_senses_soft: 12` 这条配置**现在失去存在理由**了。它的注释写的是：

```
WordNet 把一个动词的细微用法逐条列出了，这些造句也区分不开。
请在 decisions 里合并到可判别的义项。
```

「造句区分不开」不是合并理由，所以这个机制现在是在**要求错误的合并**。

改成什么：**纯数据异常告警**。cut 47 个义项确实反常（但反常不等于该砍），
提示人工看一眼，但不要求合并。如果确认都是真义项，就在 `_mergeNote` 里写明
「已逐一确认，均为独立概念」，放行。

## 保留真实义项，不管对考研有没有用

```
advantage 的 (tennis) first point scored after deuce        对考研零价值
queen 的 the only fertile female in a colony of social insects（蜂后）
cut 的 (of a male animal) having the testicles removed
stone 的 of any of various dull tannish or grey colors（灰褐色）
```

**全部保留。** 它们是英语里真实存在的义位。

用户遇到觉得没必要或太简单，自己标记学会就行——这是用户 2026-10 明确的原则：

> 「不过滤，我背单词遇到了觉得没必要或太简单，我直接标记学会了就行」

note 里可以标注「对考研无价值」供用户参考，**但不构成删除理由**。

## 对交接提示词的修改

原来那段「判断标准」整段替换成：

```
## 合并的唯一合法依据：是否同一个意思

合并只在这两种情况下合法：
1. 同一概念的不同说法（中文里能替换着用：版本/版）
2. 英文侧本来就只有一个义位（reply 的 definition 只有一条）

「造不出 5 句可区分的例句」**不是**合并理由。
那是造句阶段该花功夫的地方，不是词库阶段该砍义项的地方。

判断两个义项是否同义，问两句：
- 这两个中文词能替换着用吗？→ 能，则同义
- 换成英文，搭配集合相同吗？→ 相同，则同义

对照：
  能力 vs 才干  ——不能替换（他有能力 / 他有才干），搭配也不同 → 不合并
  版本 vs 版    ——能替换 → 合并
  切 vs 执行    ——完全不同概念，只是共用词形 → 不合并
```
