## 但补缺层暴露了一个真问题，必须单独处理

我把 `cut` 的 47 个边界逐条读了一遍：

```
cut 47 边界（ECDICT 仅 4，其余 43 全来自 WordNet）
   E31 perform or carry out            ← 「执行」，跟「切」判别不了
   E32 function as a cutting instrument
   E38 dissolve by breaking down the fat of      ← 溶脂
   E40 have grow through the gums      ← 语法都不对
   E41 grow through the gums

break 37 边界
   E19 happen or take place            ← 「发生」
   E45 happen                          ← 与上条重复
   E28 become punctured or penetrated
   E45 pierce or penetrate             ← 与上条近义
```

**这些在语言上是真义项，但造 5 句也区分不开** —— 区分「cut = 切」和「cut = 执行」
要靠语境猜，不是靠义项本身的差别。这就是背单词场景和词典场景的差别。

而 ECDICT 只收了 4 个义项，**说明它那一轮筛选其实是对的**。

## 补缺层的设计：ECDICT 全留，WordNet 只补关键义项

所以规则不是「WordNet 有就全加」，而是：

```
ECDICT 已收录的义项  全部保留（它替我们筛过一轮）
WordNet 补缺          只补「学习者能判别」的义项，且每词有上限
```

上限按**每词总义项数**计（不是补缺条数）—— 因为判别性问题是总义项太多造成的。

```
supplement_max_per_word: 12
实测需人工合并: 87 词（占 3%）
cut 47 / break 37 / call 30 / play 30 / carry 29 各需裁掉 30+ 条细分义项
>6 的词 462 个(40.7%边界)  >8: 248 词  >10: 147 词  >12: 87 词
```

87 个词的人工处理是可控工作量。**超限不静默截断** —— 砍哪几条、并进哪里是内容判断，
硬错误要求 decisions 写 `_mergeNote`。

## 补缺层的过滤规则（全在 spec.yaml，无黑盒）

```
first_word_only: true       只收以该词为首词的 synset
drop_lexnames: [noun.person]
drop_patterns: ["\\bUnited States\\b", ...]
drop_usage_domains: [colloquialism, slang, archaism, combining_form]
min_en_words: 4
```

`first_word_only` 必须开，否则：

```
wn.synsets("reply") 会返回 answer.n.01 —— 那是「答案」的义项，不是「答复」的
```

## 三个已知的规则局限（都已在 decisions 里留档）

**① `first_word_only` 会漏掉挂在别词下的义位**

```
author 在 WordNet 里只有 author.v.01 一个首词 synset。
名词义「作家」挂在 writer.n.01、「创始人」挂在 generator.n.03 —— 都被规则排除。
```

这是**真漏**（作家是本词最核心的义项）。已在 `author.json` 的 `_exceptions`
显式记录，说明这不是 bug 而是规则的已知代价。

**② `usage_domain` 覆盖极低，不能当重要性判据**

```
T1/T2 的 WordNet 独有义项 9380 条
带 usage_domain 标记: 只有 101 条 (1.1%)
```

`can = 浮标` / `will = 遗嘱` 这类 WordNet 根本没打标签。所以补缺层产出的义项
**必须逐词人工确认** —— 这也是为什么上限触发时报错而不是自动处理。

**③ 补缺后可能引入新的近义重复**

`social` 补缺后从 4 义变 7 义，其中 `wn[4] tending to move or live together in groups`
与原有 `s2 living together in communities` 同域。已在 `_mergeNote` 里说明为何都留
（一个说群体生活方式、一个说个体倾向，造句可区分），但这类判断确实需要逐词做。

## 试点结果（7 词 / 33 义项）

| 词 | 现有→v2 | 变化 |
|---|---|---|
| reply | 4→2 | 答复/回答/答辩 合并（overlap 1.00） |
| author | 2→3 | 补洞救回作家/创始人 + 英文动词义 |
| capital | 4→4 | 同义 synset 合并；补回漏掉的「首都」名词义 |
| stone | 4→**8** | 保留宝石/纪念碑 + WordNet 补缺 3 条（麻木不仁/以石击毙/灰褐色）|
| edition | 3→4 | 版本/版合并；翻版保留；英文细分出「一版」「报纸的一次发行」|

| queen | 4→5 | 加蜂后/同类之最；王后女王按英文拆开 |

**零义项被舍弃。** 全部变化是：合并同义 / 补回漏掉的 / 补洞保住零覆盖的 / 补缺新增的。
