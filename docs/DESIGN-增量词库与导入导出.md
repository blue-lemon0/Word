## 0. 前提与实测依据

```
现有卡片格式（旧）: cards.json  7884 张  1.4 MB
现有卡片格式（v2）: cards_v2.json  66 张  25 KB
学习状态:          user.db    532 KB（含 card/card_state/review_log）
```

结论：**SQLite 完全够用**。7884 张卡 + 全部 SRS 状态才 532 KB。
学 10 年也就几十 MB 量级。单文件、无服务、事务可靠，不换。

现有协议已定型，**v2 沿用并扩展**，不推翻：

```json
{
  "format": "...", "schemaVersion": 1, "version": "...",
  "stats": {...}, "glossPool": [...],
  "cards": [{
    "id": "ability#s1",          // word#senseId，稳定主键
    "word": "ability",
    "senseId": "s1",
    "pos": "n.",
    "ipa": "?b??l?t?i",
    "gloss": "中文释义",
    "glossEn": "英文释义",
    "trap": 0,
    "tier": "T1",
    "sentences": []
  }]
}
```

**核心不变：`id = word#senseId`，卡片粒度是「单词-意思对」**（不是单词）。
`sentences: []` 是允许的——缺例句不影响学习语义。

## 1. 功能点

### F1 全库骨架注入
2998 词一次性塞入，**卡片粒度 = 单词-意思对**。

| 来源 | 词数 | 义项质量 | 标记 |
|---|---|---|---|
| 已精修 | 343 | 多义项已判准，带区分线索 | `refined` |
| 待精修 | 2655 | **每词只给最核心 1 条** | `needs_refine` |

**为什么未精修的只给 1 条**（重要取舍）：
343 词的实测动作分布是 **合并 45% / 舍弃 3%**。也就是说，
自动细分义项的错误率会很高——2655 词自动拆 s1/s2/s3 会产出大量垃圾卡片。
宁可粗而准，不要细而错。用户背到该词时再补。

### F2 单词详情页：完整编辑
可改字段（全部可编辑，无一锁定）：

```
word        单词        （改后自动重建 id）
pos         词性        n./v./a./adv./vi./vt.
gloss       中文释义
glossEn     英文释义
sentences[] 例句        支持增/删/改/排序
note        备注        ← 存区分线索、误用提示
tier        分级        T1-T4
trap        易错标记    0/1
```

**新增能力（现在没有）**：
- 增删义项（s1/s2/s3…）—— 以后发现该拆开就拆
- 合并义项（s1+s2 → s1）
- 改词后自动级联更新学习状态

### F3 复制按钮（AI 补全入口）
每个词详情页一个「复制待补全模板」，产出纯文本：

```
单词: crime
词性: n.
已有释义: 犯罪，罪行（违法行为）
已有释义: 罪恶（道德上的恶，不必然违法）
英文释义: (criminal law) an act punishable by law; usually considered an evil act
英文释义: an evil act not necessarily punishable by law

请为以上每个义项各造 3 个英文例句 + 中文翻译，输出 JSON：
{"word":"crime","senses":[{"senseId":"s1","sentences":[{"en":"...","zh":"..."}]}]}
要求：例句必须能体现该义项的独特用法，能与同词其他义项区分开。
```

### F4 JSON 导入（增量）
粘贴单个词/词的完整 JSON，可选三种模式：

| 模式 | 行为 | 用途 |
|---|---|---|
| `merge`（默认） | 补 sentences、填空的 gloss/glossEn，不动已有 | AI 补例句 |
| `replace` | 该词所有义项整体替换 | AI 重做了全部 |
| `append` | 新义项追加到末尾 | 发现了新意思 |

**校验规则**（导入即校验，不通过就整份拒绝并报错）：
```
1. word 非空、无空格、合法字符
2. 每个 sense 必须有非空 gloss
3. sentences[].en 非空；zh 缺失时警告但接受
4. senseId 规范：s\d+（1..99）
5. 不允许同一词内两条义项的 glossEn 完全相同（D28：会变成重复卡片）
```

### F5 导出备份
```
文件名: wordbank_YYYYMMDD_HHMM.vwbak   ← 自定义后缀，双击打不开
内容:   zip { cards.json, state.db, meta.json, manifest }
```
含卡片 + 学习进度 + 导入历史。恢复 = 反向导入，**幂等**。

### F6 冲突与回滚
```
每次导入前自动快照 → 保留最近 10 次
导入后若发现问题，一键回滚到上次快照
```

## 3. JSON 协议

### 3.1 增量导入格式（用户侧，可手写）

```json
{
  "format": "word.import",
  "schemaVersion": 1,
  "mode": "merge",
  "word": "crime",
  "senses": [
    {
      "senseId": "s1",
      "pos": "n.",
      "gloss": "犯罪，罪行（违法行为）",
      "glossEn": "(criminal law) an act punishable by law",
      "note": "关键：受法律惩罚",
      "sentences": [
        { "en": "He was convicted of a serious crime.", "zh": "他被判犯有严重罪行。" }
      ]
    }
  ]
}
```

**容错**：允许最小形式
```json
{"word":"crime","senses":[{"gloss":"新意思","sentences":[{"en":"...","zh":"..."}]}]}
```
缺 senseId 自动分配；mode 缺省为 merge。

### 3.2 导出格式（备份用，含全部）

```json
{
  "format": "word.backup",
  "schemaVersion": 1,
  "exportedAt": "2026-10-16T12:00:00Z",
  "appVersion": "1.x",
  "stats": { "cards": 9200, "words": 2998, "learned": 340 },
  "glossPool": ["..."],
  "cards": [ /* 同现有格式，sentences 非空 */ ],
  "state": [   /* 学习状态，学习进度都在这 */
    { "id": "crime#s1", "stability": 2.3, "difficulty": 5.1,
      "lastReview": 1758000000, "nextReview": 1758086400, "reps": 7 }
  ],
  "imports": [ /* 导入历史，可追溯 */ ]
}
```

### 3.3 兼容性策略
```
schemaVersion 递增，不删旧字段
导入旧版备份：缺字段填默认值
新字段（note 等）对旧版 app 是未知键 → 忽略而非报错
```

## 4. 关键设计决策（需你确认）

### 决策 1：未精修词只给 1 条意思
- **A（推荐）**：2655 词每词 1 条核心义，标 `needs_refine`。卡片少但准。
- **B**：自动拆 2-3 条。卡片多，但约 40% 可能是错拆。

### 决策 2：senseId 是否允许重排
- **A（推荐）**：允许，且旧 id 用映射表迁移（学习状态跟着走）
- **B**：senseId 一旦生成永不变，新义项只能往后加

### 决策 3：AI 模板的例句数量
- **A（推荐）**：每义项 3 句（够区分用法，量不大）
- **B**：每义项 5 句（题库标准，但生成/粘贴量翻倍）

## 5. 实施顺序

```
阶段1  生成 2998 词骨架 bundle          （我这边，可立即做）
阶段2  app: 单词详情页就地编辑 + 增删义项
阶段3  app: 复制模板 + JSON 导入（merge/replace/append）
阶段4  app: 导出备份 + 回滚快照
阶段5  打磨：状态筛选、批量操作
```

## 6. 风险

| 风险 | 缓解 |
|---|---|
| AI 生成的例句与义项不匹配 | 导入时校验句子是否含该词的正确用法 |
| 同词义项被 AI 改乱 | 默认 merge 不动已有；replace 需确认 |
| 导入格式乱导致数据损坏 | 导入前快照 + 整份校验失败即拒绝 |
| 精修词被覆盖丢失 | 精修词导入时默认不覆盖，除非显式 replace |
