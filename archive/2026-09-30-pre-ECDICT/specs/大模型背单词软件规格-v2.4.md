## 1. 一句话定位

**一个给自己用的、可编辑的考研词汇判别训练器。**

判别 = 训练时只做选择题/判断题，答完再看中文讲解。核心动作六步：

```
看句 → 判别义项 → 判分 → 讲解（译文+义项解析）→ 标记生词 → 滚动复习
```

### 1.1 不需要的东西（已裁撤）

账号、留存优化、词书切换、考试倒计时、阶段划分、个性化推荐、真题词书。这些是"产品"的需要，不是"学会"的需要。

### 1.2 红线（不变，守死）

- 作答必须判别式（选/判），**不设中文书写作答**
- 中文讲解只在判分后展示

## 2. 核心训练闭环

### 2.1 训练单元

训练卡 = **(Word, Sense) 二元组**。同一单词的不同义项是不同训练卡，独立排期、独立计分。

### 2.2 任务形态（D12' 单一形态）

**只有一种题**：题干（句子，目标词高亮）→ 判别义项。

但干扰项来源分两种，制造难度梯度：

| 类型 | 目标词义项数 | 干扰项来源 | 难度 |
| --- | --- | --- | --- |
| 同词多义 | ≥2 义 | 同词他义（优先 TRAP）+ 跨词补足 | 中等（熟词僻义） |
| 单义词 | 仅 1 义 | 全跨词（近义词/形近词/反义词的义项） | 基础（识别） |

### 2.3 判别红线：选项延迟揭示（D12'）

1. **答题前不展示任何释义**（不变）：选项、译、讲解均不出现。
2. **题干先行**：先展示句子 + 目标词高亮，不展示任何选项。
3. **用户直面无知**：看到句子后，用户必须先独立想"这个词在这句里可能是什么意思"，
   然后**点击空白处**才显示 5 个选项。
4. **5 选项**：4 个干扰义项 + 1 个「我不会」。指到选项才看到中文释义。
5. 点击「我不会」等同"这题没答上"→ 走 PENDING 流程（§7.1）。

> 效果：单义词/多义词统一为同一交互，学习者在任何情形下都是"先猜后验"，
> 而不是"从选项里挑"。

## 3. 内容即文件（本项目最重要的工程决策）

词表、义项、例句、配置**全部是磁盘上的文本资产**，用户可直接编辑。


## 4. 词表与义项

### 4.1 词表源

使用**考研大纲词汇表**（公开文件，不自己造）。字段：

| 列 | 说明 |
| --- | --- |
| `lemma` | 原形 |
| `pos` | 词性 |
| `tier` | `CORE`（核心 3000）/ `FULL`（其余） |
| `senseIds` | 大纲给出的义项序号列表（`v1`/`v2`/…） |

### 4.2 义项表

每词一个 `senses/run.tsv`：

```
senseId   glossEn             glossZh          note
v1        to move fast        （人/动物）跑    常见义
v2        to manage / operate  经营；管理       考研陷阱义，优先练
```

**陷阱义标记**：大纲释义表中排在第 2 位及以后的义项标记为 `TRAP`。排布与 M2 辨析均优先覆盖 TRAP 义项——这是考研最易考、考生最易错的地方。

### 4.3 覆盖分层（D4）

- 默认只生成/训练 **CORE 3000**。
- 设置页可开启"覆盖全量"→ 触发剩余词的**批处理生成**，完成后本地增量合入。
- 已学的义项状态按 `lemma + senseId` 保留，不受覆盖范围切换影响。
- 低频词（FULL 层）例句质量必然略差——数学上无法避免，接受：高频词高质量兜底体验。

## 5. 例句生成流水线（开发机批处理为主，D13 补充运行时按需生成）

**主体**：生成与质检**不在 App 内运行**，在开发机上跑批，产出 assets bundle，App 离线消费。

```
Stage 0  词表输入        kaoyan_dagang_core.tsv
Stage 1  义项生成        LLM 从大纲释义产出 senses/·.tsv（TRAP 标记）
Stage 2  例句生成        LLM 按四约束，每义项 5+ 句（3 用 + 2 备用）
Stage 3  独立质检        judge LLM 逐句判定 PASS/REJECT；REJECT 重生成（上限 2）
Stage 4  打包 bundle     校验 + 签名 + 版本号 → assets.zip
```

**输入侧**：`user_flags.jsonl`（被判 REJECT 或用户点名重做的义项）在 Stage 2 优先重生成。

### 5.1 例句生成的四个约束

| # | 约束 | 判据 |
| --- | --- | --- |
| 1 | 信号可辨识 | 句中有 ≥1 个非目标词线索词，且线索词 ≠ 义项中文释义 |
| 2 | 信噪比 | 除目标词外，背景词均不在生词库，且难度 ≤ 当前水平档 |
| 3 | 新颖情况 | 同义项句子指纹不重复；同一会话内句子互不重复 |
| 4 | i+1 | 句长落在难度档区间：D1 7–12 词 / D2 12–16 / D3 14–20 |

**风格约束**：生成受控句，优先清晰、短、语境线索足，不求"像真题"。真实感是次要的，判别信号是主要的。
### 5.2 生成契约（每义项一个 JSON 块）

生成只管"句子判别信号"，**不管选项**。选项在 Stage 4 打包时从全局义项池注入。

```jsonc
{
  "senseId": "run.v1",
  "word": "run",  "pos": "vt.",
  "difficulty": 2,
  "sentences": [
    {
      "text": "She runs a small bakery with her sister.",
      "clueWord": "bakery",
      "highlightSpan": [9, 13],
      "translation": "她和姐姐一起经营着一家小面包店。",
      "note": "此处是「经营、管理」，不是「奔跑」。run a business 是固定搭配。",
      "fingerprint": "a3f1c2",
      "source": "GENERATED"
    }
  ]
}
```
### 5.2-1 选项组装（Stage 4 打包时，与句子解耦）

每个训练卡的 5 选项 = 正确义项 + 3 个干扰义项 + 「我不会」。

干扰义项选择（按优先级）：

1. **同词他义**（target 词的其他义项，TRAP 优先）
2. **跨词近义**（与 target 义项语义相近的其他词义项，从义项池按 glossZh 相似度取）
3. **跨词形近/反义**（兜底：随机取，但排除与正确义项同义的义项）

包装时为每个义项生成唯一的选项 tag（A/B/C/D/E），打乱顺序。
### 5.3 独立质检（P0-1 的核心解法）

- 质检izer 的 prompt 与生成器**完全解耦**：只看成品 + 规格，不看生成过程，否则两个判断共享同一错误假设。
- 质检判定项：目标词存在且词形匹配（G1）／句长（G2）／无生词库词（G3）／线索存在（G4）／译文含目标义项（G6）／指纹不重复（G7）。（G5 已随选项解耦移除）
- REJECT → 重生成（上限 2 次）→ 仍不合格则标记 `LOW_QUALITY`，不阻塞，留待下轮重跑。
- 质量指标只做一个：**质检 REJECT 率应 > 5%**（太低说明质检器在放水，接近 0 说明形同虚设）。

---

### 5.4 运行时按需生成（D13 · 防作弊补充）

离线池是主体，**运行时生成是兜底**，仅在以下两情形触发：

1. 某义项离线句池**已耗尽**（全部用过且用户仍要我更多检测）
2. 用户对当前句点了「这题有毛病」

触发即对该**单个对子**调用 DeepSeek 生成新句（1 句），异步后台完成、不阻塞当前卡，生成后 `source:LIVE` 单独标记、优先复用但不重复。

- 仅当 App 联网才触发；离线时静默退化为"复用已答句洗牌兜底"。
- 运行时生成句**再进入下一次复习轮换**，与池句同权。
- 质量兜底同 §5.3（迷你版：抽检 PASS/REJECT，REJECT 丢弃）。
## 6. 判分与复习（简单 SRS，D5）

**目的只有一个：决定这张卡下次什么时候出现。不做多因子调参。**

状态挂在义项级：`interval`（会话数）、`ease`（初值 2.0）。

| 结果 | interval | ease |
| --- | --- | --- |
| 首次答对 | `max(1, round(interval × 2.0))` | `min(3.0, ease + 0.05)` |
| 答对但超时/点过「我不会」 | `max(1, round(interval × 1.3))` | 不变 |
| 答错 | `1`（下一场复现） | `max(1.3, ease − 0.1)` |
| 背调生词被标记 | 不变 | 不变 |

PENDING = 选择了「我不会」或超时。单题结果枚举：`CORRECT`（计入正确率）／`WRONG`（计入）／`PENDING`（计入完成数，不计正确率）／`INVALID`（换句/跳卡，不计）。

**掌握判定**：`interval ≥ 3` 且 最近 3 次有效作答全对 且 无 PENDING → MASTERED。

**手动标记「我已学会」（D14 补充）**：任意训练卡上可选标记，一键将该对子移入 MASTERED 并跳过余下未排期的轮次。个人自用，主观判断优于任何算法——这是防冗的兜底，不与自动判定冲突：自动判定仍照常跑，手动标记只是元操作。

**复查正确率曲线**（诚实版，N2）：只统计到期的 `CORRECT/WRONG`，不允许"提前复习"混入。数据不足 20 条时显示"积累中"。这一条是给自己看的诚实镜子。

## 7. 会话

- 长度：**5 / 10（默认）/ 20** 三档 + 随时可停。
- 排布：到期复习（间隔到）→ 生词库优先 → 新义项（TRAP 优先 → CORE）→ 未安排补位。会话开始一次性定死，结束后不再重排。
- 断点续学：上次停在哪，下次从哪继续，首页主按钮=「继续训练」。
- 「练 1 题」入口常驻：一键做完马上走，不弹结算页，进度照常落库。

### 7.1 超时与「不会」（P1-2 反转）

- 主动点「不会」：先展示答案+讲解，再可选「再做一次」。记为 PENDING。
- 超时（如开启）：仅高亮「不会」按钮，不强制、不记错、不惩罚。
- 允许在设置关闭超时。

**"慢 ≠ 弱"**：PENDING 不触发"降难度"——个人自己知道难不难，无须系统代判。降难度只由明显信号触发：**同一义项连续 3 次 PENDING → 该义项难度 −1 档**。

### 7.2 多生词句（简化）

标记 ≥2 个背景生词 → 本题记 `INVALID`（不计分），换备用句（难度 −1 档）。连续换 2 次仍不合格 → 跳过该卡。标记的生词照常进生词库。

### 7.3 小结页（D14 · 完整场次才弹）

- **只在完整走完一场（5/10/20）时展示**；「练 1 题」与随时暂停不弹，兼容 §7 的"轻结算"哲学。
- 极简 4 行，无曲线图、无表演：
  ```
  本场：新学 5 · 对 8 · 错 3 · 不会 2
  错过：abandon·抛弃 / 细(shrewd)
  复习达标：2 个义项 MASTERED
  → [看详情] [再来一轮]
  ```
- 「错过」列出本场判错/不会的对子，点一项即进"单挑"（见 §8.2）——小结页是错题板的引导入口之一。

## 8. 生词库与错题板

### 8.1 生词库（个人简化版）

- 任意题点选背景词 → 标记 → 入库（标记即持久化，可撤销）。
- 生词优先进入次日排布（第 1 题）。
- 「其实我认识」→ 移除。没有复杂的 40 上限与插队模型——个人积压量小。
- 生词库待训练目标词在底部 tab 可见，常驻顶行显示：`N 个生词等待训练`。

### 8.2 错题板（D14 · 可见层，不动排布）

- **它是"生词库的自动版"**：生词库收用户主动标记 + 背景词；错题板**自动累积**"判错 / 点过没关系但判错过 / PENDING"的对子（`lemma#sense` 粒度）。
- **纯可见层，不参与排布调度**：排布仍由 §6/§7.1 的复现规则负责（答错 → 下一场自动复现）。错题板只提供一个**聚合的、按权重排序的手动入口**——个人自用，你知道哪里弱。
- **排序权重**：判错多次 > 判错过一次 > 点过不存在（PENDING）。每对子记录 `错次数 / 最近错时间`（SRS 状态里已有，排序即得）。
- **单挑**：点一个对子 → 立即练它（不限题数，连续与自动排布无关）。最终"学会"仍计入 SRS。
- **降级规则**：连续 2 次答对 或 手动「我已学会」→ 从错题板移除（但 SRS 历史保留）。

## 11. 可靠性边界（"稳定"验收项）

| 项 | 要求 |
| --- | --- |
| 断网 | 训练全程可用（内容本地） |
| 崩溃恢复 | 任意题际被杀，重启续到下一题不重复计分 |

| 无依赖 | 启动到可练 < 2s；句子呈现 < 100ms（命中本地） |
| 数据 | 生词/进度每次操作即存，不依赖批处理/网络 |

## 12. 分期（轻）
