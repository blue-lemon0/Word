# Prompt · Stage 1 义项解析

> 输入：考研大纲词表的原始释义字段（`gloss`）。
> 输出：该词的结构化义项列表（供后续例句生成与判别训练使用）。

## 任务说明

把大纲给出的**合并释义串** (如 `经营、管理；奔跑` 或 `问题；流出；期号；发行物`)
拆解为一组**可独立判别**的义项。

## 拆分原则

1. **只保留大纲释义中出现的义项**，不补充大纲未列的义项。
2. **每个义项 = 一个可单独出判断题的语义单元**。同义词、近义表述合并为一个义项：
   - `放弃；抛弃；离弃` → 一个义项（都是 give up）
3. `；` 或 `，` 分隔的多义项**分别列出**，除非是 2 的同义变体。
4. 义项顺序 = 大纲出现的顺序；第 2 位及以后是**考研陷阱义（TRAP=true）**，
   因为用户已熟记第 1 义，需要特别训练。
5. 区分不了是"同义变体"还是"独立义项"时：若可以在一个例句里轻松同时成立 → 同义合并；
   若需要不同例句才能分别成立 → 独立义项。

## 输出格式（严格 JSON）

```json
{
  "senses": [
    {
      "senseId": "v1",
      "pos": "vt.",
      "glossZh": "放弃；抛弃",
      "glossEn": "to give up; to abandon",
      "trap": false,
      "note": ""
    }
  ]
}
```

`senseId`：统一格式 `s1, s2, s3 ...`（不含词性字母，与词性解耦）。
`pos`：标准词性缩写（n. / v. / vt. / vi. / adj. / adv. / prep. / conj. / pron. / num. / int. / art.）。
`note`：仅在需要消歧、但又是同义合并时填写简短说明；一般留空。
`trap`：义项在列表中的位置 ≥2 时为 `true`，第 1 义为 `false`。

> 语义非常接近的两个义项（如"精通 master"与"掌握 master"）必须合并为一个，
> 不得拆开。词性相同时优先合并动词义。
